# Security

This is a static site with no logins and no forms. Payments happen in the Wix store, not here.
If you find a security problem (for example a link that leads somewhere unsafe), please report it privately:
Security tab → "Report a vulnerability". Please do not open a public issue. We reply within 7 days.
