Conditionals: zero to mixed

All four main conditional patterns plus mixed conditionals, in one table.

Download PDF

Conditionals connect a condition (the if clause) with a result. The tense you choose shows how real or likely the situation is.

TypeFormUseExample
Zeroif + present, presentGeneral truthsIf you heat ice, it melts.
Firstif + present, will + verbReal future possibilityIf it rains, we'll stay home.
Secondif + past, would + verbUnreal or unlikely present or futureIf I had more time, I'd learn Japanese.
Thirdif + past perfect, would have + past participleUnreal pastIf I had left earlier, I would have caught the train.
Mixedif + past perfect, would + verbPast condition, present resultIf I had studied medicine, I would be a doctor now.
Formal style. You can drop if and invert: Had I known, I would have called. Should you need help, ask.
Common mistake. Never put would in the if clause. Say If I knew, not If I would know.

Practice

  1. If she ___ (call) me yesterday, I would have helped.
  2. If I ___ (be) you, I'd apologise.
  3. If you ___ (press) this button, the machine starts.
  4. If he hadn't missed the flight, he ___ (be) here now.
  5. Rewrite with inversion: If I had known about the meeting, I would have come.
Show answers
  1. had called
  2. were
  3. press
  4. would be
  5. Had I known about the meeting, I would have come.
