# Sketch to Motion: image prompts for 10 videos




## How to use this file

1. Paste each prompt into your image tool at **9:16**. Each prompt is complete on its own.
2. For a consistent hand, generate `v01_01` first and use it as the style reference for the rest.
3. Name each file as shown in its heading, for example `v03_07.png`.
4. Upload them to `your project's drawings folder`, then ask your coding agent to build each video from them.
5. Skipping or redrawing a frame is fine. The timing adjusts to however many drawings a video has.

The drawings set the layout and subject. They stay black and white on purpose, so the jump to full colour is the payoff. No real brand logos are used, so you can post these freely; a brand-themed version is an easy swap.
