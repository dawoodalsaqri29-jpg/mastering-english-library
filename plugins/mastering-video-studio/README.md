# Mastering Video Studio

Everything needed to make Mastering English Library videos from code.

- `video-studio`: start here. It picks the style, writes the scenes, voices them with Kokoro Isabella and renders 4K.
- 19 style skills: anime, archival-doc, cartoon, chibi-history, city-timelapse, comic-book, doodle-world, flat-vector, founder-story, ink-anatomy, isometric, map-reveal, painted-history, pictogram, pixel-quest, stick-figure, stopmotion-paper, storybook, whiteboard-hand.
- `sketch-to-motion`: the drawing-to-3D Shorts format, including "Name it before I do!".

The painted-history engine includes a fix: armies from before gunpowder no longer get cannons.
Setup steps are in `skills/video-studio/SKILL.md`.
