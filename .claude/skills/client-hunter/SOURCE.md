# Source

Copied word for word from the free "Client Hunter Skill Guide" PDF by Max Johnson (@maxjohnscn, briix.ai),
chapter 08, received from the owner on 2026-11-07. The PDF states no licence; it is offered free to copy.

Reviewed before adding: it is instructions only, with no scripts. It searches public web pages, never sends,
posts or contacts anyone (it drafts messages for the owner to send), never uses private contact details and
never gets round a block.

Cost: one hunt runs 12 sub-agents searching the web, several minutes, and can send the scouts out again up to
two times. Run it when the owner asks; it is not on a schedule.

The owner's profile for Step 0 is in `.claude/team/client-profile.md`. Read it first so the hunt does not
have to ask again.
