# Source of the founder-* skills

The eleven `founder-*` folders in `.claude/skills/` are copied unchanged from
[Jakeschincariol/founder-skill](https://github.com/Jakeschincariol/founder-skill),
pinned to commit `fd9385b0cfe1b96bebce3898fbd506d73eff5a9d` (2026-10-06). MIT licence:
see `FOUNDER-SKILL-LICENSE` in this folder.

Reviewed on 2026-11-08 before install: no hooks, no network calls, no API keys; the four
Python helpers (`unit_economics.py`, `panel.py`, `compile.py`, `van_westendorp.py`) use only
the standard library. The plugin manifest and tests were not copied. To upgrade, review the new
commit first and change the hash here.
