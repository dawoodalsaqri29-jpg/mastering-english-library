# Bundled Fonts

This skill bundles six typefaces, each licensed under the SIL Open Font License (OFL) v1.1. The OFL allows free use, modification, and redistribution for both commercial and non-commercial purposes. Each font's license text is included alongside the font files.

## The fonts

| Family | Style | Use for | Files | Source |
|---|---|---|---|---|
| **Inter** | Modern sans-serif | Default. Clean, neutral, works for tech/SaaS/general business. Variable weight 100–900. | `Inter/Inter-Variable.ttf`, `Inter/Inter-Italic-Variable.ttf` | [rsms/inter](https://github.com/rsms/inter) |
| **Playfair Display** | Editorial serif | Prestige, classic, magazine-style. High contrast, drawn for display sizes. Variable weight 400–900. | `Playfair_Display/PlayfairDisplay-Variable.ttf`, `Playfair_Display/PlayfairDisplay-Italic-Variable.ttf` | [Google Fonts](https://fonts.google.com/specimen/Playfair+Display) |
| **Bebas Neue** | Condensed display | News, sports, headline impact. Single weight, all-caps optimized. | `Bebas_Neue/BebasNeue-Regular.ttf` | [Google Fonts](https://fonts.google.com/specimen/Bebas+Neue) |
| **Space Grotesk** | Geometric sans | Startup, technical, fresh. Slightly quirky, modern. Variable weight 300–700. | `Space_Grotesk/SpaceGrotesk-Variable.ttf` | [Google Fonts](https://fonts.google.com/specimen/Space+Grotesk) |
| **Lora** | Humanist serif | Warm, literary, friendly. Reads well at all sizes. Variable weight 400–700. | `Lora/Lora-Variable.ttf`, `Lora/Lora-Italic-Variable.ttf` | [Google Fonts](https://fonts.google.com/specimen/Lora) |
| **Anton** | Heavy display | Bold magazine, posters, big type. Single weight. | `Anton/Anton-Regular.ttf` | [Google Fonts](https://fonts.google.com/specimen/Anton) |

## Custom font

If you'd rather use your own brand font, the skill supports pointing at any TTF or OTF file on your machine. During onboarding, pick "Custom" and provide the path. The skill will use that font for all carousels.
