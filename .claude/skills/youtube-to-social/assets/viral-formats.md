# Viral Short-Form Video Format Library

A condensed reference of 27 short-form video formats organized by category. Use this every time a script is generated. Pick the format that best matches the substance of the source material, then build the script on its structural skeleton.

Read the full library before generating. After picking a format, the structure of that specific format dictates the shape of the script — these aren't all the same hook → setup → payload → close arc. Different formats have different scaffolds.

---

## How to pick a format

Match the substance to the format, not the other way around. Quick guide by what the source material gives you:

- **A strong claim that needs proving** → Show Your Receipts, Payoff Promise Up Front
- **A common mistake or anti-pattern** → Reverse Tutorial, Don't Do This
- **A spectrum of skill or sophistication** → Five Levels
- **A real artifact (post, page, design, work)** → Walk-Through Annotation, Before & After Decode
- **A surprising story with a turn** → Plot Twist Story, In-Media-Res Drop
- **A transformation over time** → Then vs. Now, Streak
- **A constraint, deadline, or arbitrary rule** → Constraint, Speedrun, Underdog Setup, Countdown
- **A character or relationship** → Recurring Character, Stranger of the Day
- **A single moment of process** → Slow Build, Slow Reveal, Loop
- **A specific yes/no question** → Question Held Open
- **A piece of evidence (text, screenshot, voicemail)** → Artifact Open
- **A pattern → break punchline** → Three-Part Setup
- **A "this looked like it was failing" arc** → Fake Fail
- **A reverent treatment of a small subject** → Documentary Mini-Episode
- **A submission-style audit** → 30-Second Audit
- **A pricing reveal** → What I Charge For This
- **An honest verdict from outsiders** → Public Verdict

When the source material has multiple possible angles, surface 2-3 format options to the buyer with one-line descriptions and let them pick. Don't pick silently if multiple formats fit.

## Category 1: Challenges

### Speedrun
**Structure:** State the previous record / benchmark → start the timer → attempt the task → land it (or don't) → final time on screen. Onscreen timer must be visible the whole script.
**Best for:** A familiar task where speed is meaningful. Source material has a clear, repeatable process.
**Hook pattern:** "Last time, [task] took me [time]. Today I'm trying for under [number]."
**Script note:** Mention the timer in the dialogue ("clock's ticking", "we're at 4:30 with two minutes left").

### Constraint
**Structure:** State the artificial limit in 3 seconds → attempt the task while the constraint is on screen → navigate the limit → show the result.
**Best for:** A normal output the buyer's audience knows, made interesting by an arbitrary rule.
**Hook pattern:** "I'm going to [normal task] but [weird constraint]." Examples: "...using only one pan." "...in exactly 50 words." "...with no [tool everyone uses]."
**Script note:** Restate the constraint at least once mid-script so viewers who joined late understand the stakes.

### Streak
**Structure:** Number = the hook ("I did X for N days"). Quick montage of the journey → the unexpected thing that changed → honest reveal of what actually shifted (and what didn't).
**Best for:** A long arc that compresses into one piece. Source material discusses sustained practice or transformation.
**Hook pattern:** "I [verb] every day for [N] days. Here's what actually happened."
**Script note:** Don't overpromise the result. "Here's what actually happened" outperforms "this changed my life."

### Random Selection
**Structure:** Surrender choice to a visible random source (wheel, generator, comments) → react to whatever lands → execute the task → show the result.
**Best for:** A repeatable challenge where unpredictability adds drama. Source material covers a category broad enough that any random pick is interesting.
**Hook pattern:** "I let [random source] pick [variable] — and now I have to [task]."
**Script note:** The randomization must happen on screen. Off-screen rolls feel rigged.

### Underdog Setup
**Structure:** State the deficit upfront in numbers ("$50", "one hour", "a 2017 phone") → attempt the task with deliberately stacked deck → show resourcefulness in real time → reveal final result.
**Best for:** Source material implies aspirational outcomes that normally need big resources. Buyer wants to teach resourcefulness.
**Hook pattern:** "[Premium outcome] on [absurdly low resources]."
**Script note:** Even partial success counts as a win. The framing is "look what's possible," not "watch me succeed perfectly."

### Public Verdict
**Structure:** Show the work or attempt → take it to strangers → no defense, no explanation → capture honest reactions → tally the verdict.
**Best for:** Source material covers craft, taste, or claims that benefit from external validation.
**Hook pattern:** "Rate my [thing] — and tell me what's wrong with it."
**Script note:** Strangers must feel free to be brutal. If everyone is polite, the format dies. The script should set up the buyer welcoming criticism, not seeking validation.

## Category 2: Education

### Walk-Through Annotation
**Structure:** Pull up a real artifact → narrate over it explaining each decision → zoom on specific elements → leave the viewer with the principle.
**Best for:** Source material teaches pattern recognition or taste. Buyer wants to dissect, not theorize.
**Hook pattern:** "Look at [specific real artifact]. I'm going to walk through every decision that makes it work."
**Script note:** Real example > hypothetical example. If permission for the artifact is unclear, focus on what works rather than tearing it apart.

### Before & After Decode
**Structure:** Lead with side-by-side comparison in first 3 seconds → break down each specific change → end on the takeaway pattern.
**Best for:** Source material is about a transformation or improvement that comes from a small handful of specific decisions.
**Hook pattern:** "Same [thing], two versions — one [bad outcome], one [good outcome]. Here's what changed."
**Script note:** Every callout should be a concrete decision a viewer could replicate. Avoid generic advice.

### Show Your Receipts
**Structure:** State the claim → show the actual evidence (screenshot, statement, dashboard) → walk through what it proves → name the principle.
**Best for:** Source material makes a strong claim that the buyer's audience would naturally doubt.
**Hook pattern:** "I said [specific claim]. Here's the proof."
**Script note:** Always blur or crop sensitive info. Specific numbers and dates are what matter.

### Reverse Tutorial
**Structure:** Frame as how to GUARANTEE failure → walk through every wrong move methodically → deliver it deadpan as if the bad advice is real → trust the audience to invert.
**Best for:** Source material covers common mistakes or anti-patterns. Buyer's voice handles deadpan/sarcasm.
**Hook pattern:** "Here's how to guarantee [bad outcome]." or "A masterclass in [doing it wrong]."
**Script note:** Don't break character to "really mean" the right way. The whole script lives in the inversion.

### Five Levels
**Structure:** Same skill at 5 escalating levels — beginner, intermediate, advanced, expert, master. Each level a distinct attempt. Categorical jumps, not incremental polish.
**Best for:** Source material covers a discipline with a clear skill spectrum. Buyer can credibly speak to all 5 levels.
**Hook pattern:** "Five levels of [skill] — beginner to [master tier]."
**Script note:** If level 2 just looks like level 1 with more polish, the format collapses. Make each level feel categorically different.

### 30-Second Audit
**Structure:** Pull up real submitted work → call out 3 highest-impact problems → give specific fixes → end on screen with what to change.
**Best for:** Source material covers diagnosis or quality assessment. Buyer wants to demonstrate eye/authority.
**Hook pattern:** "30-second audit of [submitted thing]. Three things to change."
**Script note:** Be precise and useful, not cruel. Best when subject has actively requested the audit.

### What I Charge For This
**Structure:** Show the work → walk through the deliverables/scope → reveal the price → let viewers debate.
**Best for:** Source material discusses pricing, value, or service-business pricing transparency.
**Hook pattern:** "[Specific work]. [Hours/scope]. [Price]."
**Script note:** Real numbers only. Inflated prices get sniffed out. Lower-than-expected prices often outperform aspirational ones.

### Don't Do This
**Structure:** Name ONE specific mistake in the hook → show why it backfires → give the one-sentence fix → end. Under 30s.
**Best for:** Source material has a specific anti-pattern that a viewer could correct in one sentence.
**Hook pattern:** "Don't [specific mistake] — and here's why."
**Script note:** Stay ruthlessly focused on one mistake. Adding a second one collapses the format's punch.

## Category 3: Storytelling

### In-Media-Res Drop
**Structure:** Open mid-action, mid-sentence ("...and that's when she handed me the receipt") → pull back and explain how we got here → resolve the moment.
**Best for:** Source material contains a story with a single sharp moment that benefits from being teased before being explained.
**Hook pattern:** "...and that's when [consequential thing happened]." (Open with ellipsis, no setup.)
**Script note:** The mid-action moment must be genuinely consequential. Dramatic open + mundane story = clickbait.

### Stranger of the Day
**Structure:** Name the stranger in the hook → describe the most surprising thing about them → tell the story or moment → land on what made it stick.
**Best for:** Source material contains real character portraits or memorable encounters.
**Hook pattern:** "Stranger of the day: the [person] who [specific surprising trait]."
**Script note:** Get permission before featuring real people. A boring stranger told well outperforms an interesting stranger told badly.

### Artifact Open
**Structure:** Open with a real piece of evidence on screen (screenshot, voicemail, text) → let the viewer read it → narrate the story it triggered → close with what happened.
**Best for:** Source material includes a specific piece of communication or evidence that triggered a story.
**Hook pattern:** Open with the artifact itself, dialogue starts after the viewer has seen it.
**Script note:** Blur names and sensitive info. Get permission for anything identifiable.

### Then vs. Now
**Structure:** Lead with the side-by-side comparison in first 3 seconds → walk through specific decisions/moments that bridged the gap → end on the current state.
**Best for:** Source material covers personal or professional transformation with verifiable before-after states.
**Hook pattern:** "[Past state] vs. [present state]." Show both immediately.
**Script note:** Authenticity matters more than dramatic difference. A small but real transformation outperforms a large but cosmetic one.

### Plot Twist Story
**Structure:** Tell a story that seems to mean one thing → set up a particular emotional read → reveal a single fact at the end that flips the interpretation.
**Best for:** Source material contains a story where the obvious read is wrong. Twist must recontextualize, not just surprise.
**Hook pattern:** "I thought [first reading]. Then [single fact that flips it]."
**Script note:** Twist must feel surprising but inevitable in hindsight. Plant clues. Don't over-engineer.

### Documentary Mini-Episode
**Structure:** 60-90s. Adopts long-form doc pacing — slow B-roll, voiceover, light music, reflective tone — applied to a small or unexpected subject.
**Best for:** Source material has a humble, specific subject that benefits from reverent treatment.
**Hook pattern:** A quiet, declarative line that signals seriousness about a small subject.
**Script note:** Voiceover quality, music, and pacing carry the format. The buyer's delivery should be slower and more measured than their normal voice.

### Recurring Character
**Structure:** Name the character → reference their established pattern → tell the new episode → land on what makes this one different.
**Best for:** Source material describes a person who could anchor a series across multiple videos.
**Hook pattern:** "[Character name] is back." (Or for the first episode: "Meet [character name].")
**Script note:** Develop the character honestly. Pure caricature gets old fast. Give them edges — likability, complexity, vulnerability.

## Category 4: Delayed Payoff

### Slow Build
**Structure:** Single uninterrupted shot. Static camera. Watch something get built/prepped/assembled in real time. Patience is the offer; the final state is the payoff.
**Best for:** Source material describes a process that's interesting to watch unfold in real time.
**Hook pattern:** Often no spoken hook — the visual itself is the hook. If a hook is needed: "Watch this come together in real time."
**Script note:** Ambient sound > music. Real sounds (knife, paper, tools) sell the honesty.

### Three-Part Setup
**Structure:** Establish a pattern in beats 1 and 2 → break it in beat 3 → land the contrast.
**Best for:** Source material contains a pattern that can be set up cleanly and then broken for effect (comedy, surprise, or escalation).
**Hook pattern:** "[Beat 1 statement]. [Beat 2 matching statement]. [Beat 3 break]."
**Script note:** Beats must be visually parallel. Same framing. The break in beat 3 is what lands.

### Fake Fail
**Structure:** Make the entire video LOOK like the attempt is going wrong → real near-misses, real frustration → final move reveals the failures were the technique all along.
**Best for:** Source material covers a craft where the path to mastery includes apparent setbacks.
**Hook pattern:** Something that signals stakes — "I've been trying to get this for an hour."
**Script note:** Apparent failures must be real near-misses, not pantomimes. If the failures look fake, the format collapses.

### Slow Reveal
**Structure:** Build something using only tight crops, partial views, edges — never the full subject → final reveal at the end shows the whole thing.
**Best for:** Source material describes a finished thing where the reveal is satisfying. Highly visual content.
**Hook pattern:** A close-up of a fragment + a teasing line: "I'm building something. You'll see it in 60 seconds."
**Script note:** Resist the temptation to give one full glimpse before the reveal. Every shot before the final one must be a fragment.

### Payoff Promise Up Front
**Structure:** Open with explicit, specific commitment ("Stay until the end and I'll show you [tangible thing]") → build context and credibility → deliver the named payoff at the close.
**Best for:** Source material contains a specific actionable artifact (an exact phrase, an exact recipe, an exact rule) that's worth promising.
**Hook pattern:** "Stay until the end and I'll show you [specific, tangible, verifiable thing]."
**Script note:** The promise must be honest. Modest promise + slight over-deliver beats grand promise + mediocre delivery.

### Loop
**Structure:** Engineer the script so the last frame matches the first. Viewer rewatches without realizing.
**Best for:** Source material describes a cyclical process or has a clean visual entry/exit.
**Hook pattern:** No verbal hook — the matching first/last frames are the structural device.
**Script note:** Plan the loop point first, then build the script toward it from both ends.

### Countdown
**Structure:** Visible counter on screen ticking toward an event → action plays out as the counter advances → resolution lands when counter hits target.
**Best for:** Source material involves a real timer, deadline, or finite event.
**Hook pattern:** "[Counter] until [event]. Watch."
**Script note:** Counter must correspond to a real event. Fake countdowns get sniffed out and damage future watch time.

### Question Held Open
**Structure:** Pose a specific yes/no question in the hook → build evidence in BOTH directions → reveal the answer only at the final beat.
**Best for:** Source material answers a specific, surprising question. The question must be specific enough to matter and uncertain enough to actually need answering.
**Hook pattern:** "Can I [specific, surprising thing]?"
**Script note:** Don't leak the answer mid-script. Build evidence on both sides before the reveal.

## Cross-format principles

**Specificity is the multiplier.** Every format above gets stronger as the specifics get sharper. "A budget meal" → "a five-star dinner for $4.83." "A common mistake" → "Don't say 'just checking in' in a follow-up email." Pull specific numbers, names, examples, and claims out of the transcript and use them. If the transcript doesn't have specifics, the format will land softer.

**Hook discipline.** Each format lives or dies on its first three seconds. The hook patterns above are starting points — write the hook separately from the body, and try 2-3 variations before settling.

**Format stacking is allowed.** A Constraint inside a Slow Build. A Plot Twist inside an Artifact Open. A Five Levels inside a Speedrun. These aren't mutually exclusive categories — they're vocabulary the buyer can combine.

**Scripts run 30-60 seconds (75-150 words spoken).** This is the script length regardless of format. Some formats (Slow Build, Loop, Documentary) lean toward the longer end; others (Don't Do This, Three-Part Setup) lean shorter.
