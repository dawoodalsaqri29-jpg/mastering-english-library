# Short prompt for an AI video engine (Veo / Kling / ElevenLabs Video) — only when a shot needs what the rig can't do
(turning the head toward the camera, hands, hugging, cloth physics). Never paste the workflow into the engine.

Template (fill, keep it under ~90 words; dialogue goes in the engine's own audio/lip-sync field, not here):
"2D anime dialogue shot, clean lines, consistent cel shading. Keep the reference character exactly: <locked block:
age, face shape, eye colour, hair style/colour, outfit>. She <action: one clear movement>, <expression>, speaking
calmly with mouth movement matching the voice and small head nods on the stressed words. Hair roots move with the
head, curl tips follow slightly later then settle. Head, neck and shoulders move as one body. <camera: static medium
close-up / slow push-in>. Background <scene>, stable, same lighting from <direction>. Brief still moments."

Negative field (only if the engine has one): "extra teeth, melting face, changing hairstyle, flickering lines,
background warping".
Check the result with the same defect table (anime-defects.md) before using it.
